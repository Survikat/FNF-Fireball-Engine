# Asset Licenses
This document is a continuation of Surv's Asset License, which should be located within the same directory of this document. This file dictates what licenses specific directories or files fall under, with headers of the copyright holder's name being listed above if applicable. However only the "Apache 2.0 License" or "Surv's Asset License" can be chosen.

## Directory Licenses
This section specifies directories with primary licenses listed by default for said directories. This does not mean every asset falls under the given primary license.

`~/assets/data` - This directory might not fall under Surv's Asset license, it will primarily follow the Apache 2.0 License.
`~/assets/images` - This directory might not fall under the Apache 2.0 License, it will primarily follow Surv's Asset license.
`~/assets/songs` - This directory might not fall under the Apache 2.0 License, it will primarily follow Surv's Asset license.
`~/assets/sounds` - This directory might not fall under the Apache 2.0 License, it will primarily follow Surv's Asset license.

## Template
Asset Copyright Sections must work under the following template:
```txt
## Copyright Holder
(Any applicable notes, requests, or additional license definitions that break format. This is optional!)

Asset Licenses:
- The asset located in `directory` falls under the (applicable license here).
- The directory `directory` primarily falls under the (applicable license here).
```

Please note that `~` will and should be used to refer to the root of the project's directory.
